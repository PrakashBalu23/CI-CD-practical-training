# CI/CD Practical Training

## Project Description
This project is created to practice Git, GitHub, Maven, Java and GitHub Actions.

## Tasks

### Task 1 – Git and GitHub Workflow
- Create a GitHub repository.
- Practice branching and committing.
- Push code to GitHub.
- Create and merge Pull Requests.
- Resolve merge conflicts.

### Task 2 – First CI Pipeline
- Develop a Java Calculator application.
- Configure JUnit 5 test cases.
- Configure Maven.
- Create a GitHub Actions CI workflow.
- Verify successful and failed pipeline executions.

### Task 3 – Maven Build Practice
Practice the following commands:
- `mvn clean`
- `mvn compile`
- `mvn test`
- `mvn verify`

## Technologies Used
- Java 17
- Git
- GitHub
- Maven
- JUnit 5
- GitHub Actions
